# Windows 검증

## Windows 1.0 정식 배포 — 2026-09-29

Mac과 같은 v1.0.0 태그(fc6784540be788daa270d65270addc72ef205571)에서 Windows x64 자체 포함 실행 파일과 설치 EXE를 로컬 빌드했습니다. 실제 WebView2 통합 검사 **245/245 통과**. 설치 EXE로 기존 설치 업그레이드, 버전 1.0.0, 바이너리 해시 일치, 설정 보존 및 .md/.markdown 등록을 확인했습니다.

[정식 릴리즈](https://github.com/thlee/mdbom/releases/tag/v1.0.0)에 설치 EXE·포터블 ZIP·SHA256SUMS-Windows.txt를 제공합니다. GitHub에 게시한 EXE·ZIP의 SHA-256과 로컬 파일이 일치합니다. Actions는 켜지 않았습니다. 이번에 새 계정에서 전체 설치·제거 수명주기나 저장 대화상자의 모든 수동 경로를 재검사하지는 않았습니다.

배포 바이너리는 태그 소스 그대로입니다. 동봉 도움말 일부에 남아 있는 Windows 배포 대기 문구와 달리 1.0은 HTML 내보내기를 포함합니다.

## HTML 스크롤 수정 — 2026-09-28

실제 WebView2에서 **237/237 통과**했습니다. 기존 검사에 20개를 추가해 네 가지 보기에서 저장한 HTML을 별도 WebView2로 열고, 800px·390px 창에서 스크롤과 마지막 문단 표시를 확인했습니다. 이전 HTML과 같이 루트 레이아웃 속성이 없으면 `overflow:hidden`이 적용되는 것도 확인했습니다. 내보내기 코드와 내장 도움말을 포함한 최종 Windows 빌드로 실행한 결과입니다.

[공개 저장소의 자동 검증](https://github.com/thlee/mdbom/actions/workflows/build.yml)을 기준으로 배포합니다.

실제 WebView2에서 문서 표시·검색·분할·설정 저장·보안 제한·인쇄를 확인하고, 별도 임시 계정에서 설치·재설치·제거와 사용자 설정 보존을 검사합니다. 설치 수명주기 검사는 개발자의 일반 계정에서 실행하지 않습니다.

검증 결과와 설치 파일은 성공한 실행의 아티팩트에서 확인할 수 있습니다.

## HTML 내보내기 개발 빌드 — 2026-09-27

- 자체 포함 x64 앱의 실제 WebView2 통합 검사: **217/217 통과**.
- 문서·소스·좌우·상하 보기에서 실제 내보내기 생성 경로를 실행해 HTML 본문, 내장 스타일·이미지, 수식·다이어그램, 테마, 제목 이스케이프, 외부 자산 및 앱 내부 링크 제외를 확인했습니다.
- HTML 버튼을 인쇄 왼쪽으로 옮긴 후 자산 해시 검사와 재빌드를 완료했습니다. 아이콘 순서만 변경한 빌드에 전체 검사를 반복하지 않았습니다.
- 로컬 설치 파일과 빌드한 실행 파일의 해시 일치, 사용자 설정 보존을 확인했습니다. 이번 작업에서 설치 프로그램의 전체 설치·제거 검사를 새로 수행한 것은 아닙니다.
- 실제 저장 창의 취소·덮어쓰기·권한 오류와 별도 브라우저 시각 검증은 남아 있습니다. Mac 상태와 정식 출시 전 확인 항목은 [공통 검증 기록](../VERIFICATION.md)을 참고하세요.

이 결과는 Beta 4 이후 개발 빌드의 기록이며 공개 Beta 4 설치 파일에 HTML 내보내기가 있다는 의미가 아닙니다.
