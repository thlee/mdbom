# Windows 검증

[공개 저장소의 자동 검증](https://github.com/thlee/mdbom/actions/workflows/build.yml)을 기준으로 배포합니다.

실제 WebView2에서 문서 표시·검색·분할·설정 저장·보안 제한·인쇄를 확인하고, 별도 임시 계정에서 설치·재설치·제거와 사용자 설정 보존을 검사합니다. 설치 수명주기 검사는 개발자의 일반 계정에서 실행하지 않습니다.

검증 결과와 설치 파일은 성공한 실행의 아티팩트에서 확인할 수 있습니다.

## HTML 내보내기 개발 빌드 — 2026-09-27

- 자체 포함 x64 앱의 실제 WebView2 통합 검사: **217/217 통과**.
- 문서·소스·좌우·상하 보기에서 실제 내보내기 생성 경로를 실행해 HTML 본문, 내장 스타일·이미지, 수식·다이어그램, 테마, 제목 이스케이프, 외부 자산 및 앱 내부 링크 제외를 확인했습니다.
- HTML 버튼을 인쇄 왼쪽으로 옮긴 후 자산 해시 검사와 재빌드를 완료했습니다. 아이콘 순서만 변경한 빌드에 전체 검사를 반복하지 않았습니다.
- 로컬 설치 파일과 빌드한 실행 파일의 해시 일치, 사용자 설정 보존을 확인했습니다. 이번 작업에서 설치 프로그램의 전체 설치·제거 검사를 새로 수행한 것은 아닙니다.
- 실제 저장 창의 취소·덮어쓰기·권한 오류와 별도 브라우저 시각 검증은 남아 있습니다. Mac 상태와 정식 출시 전 확인 항목은 [공통 검증 기록](../VERIFICATION.md)을 참고하세요.

이 결과는 Beta 4 이후 개발 빌드의 기록이며 공개 Beta 4 설치 파일에 HTML 내보내기가 있다는 의미가 아닙니다.
