# 엠디봄 · MDBom

마크다운 문서를 가볍게 보다.

**현재 베타: 1.0.0-beta.3 (1.0 베타 3).** macOS와 Windows용 읽기 전용 Markdown 뷰어입니다. 두 앱은 같은 렌더러·본문 스타일·도구 패널을 사용하며, 창과 파일 처리는 운영체제별 네이티브 코드로 구현합니다. Electron이나 별도 서버 없이 번들 자산으로 오프라인 렌더링합니다.

개인적으로 개발해 공유하는 오픈소스 프로그램이며, 농촌진흥청의 공식 프로그램은 아닙니다.

## 설치와 업데이트

[**1.0 베타 3 다운로드**](https://github.com/thlee/mdbom/releases/tag/v1.0.0-beta.3) · [**사용설명서**](HELP.md)

| 운영체제 | 설치 파일 | 설치 방법 |
| --- | --- | --- |
| Windows 10 22H2 / 11 x64 | [설치 EXE](https://github.com/thlee/mdbom/releases/download/v1.0.0-beta.3/MDBom-1.0.0-beta.3-Setup-x64.exe) | 내려받은 파일 실행 |
| macOS 14 이상 · Apple Silicon | [설치 DMG](https://github.com/thlee/mdbom/releases/download/v1.0.0-beta.3/MDBom-1.0.0-beta.3-macOS-arm64.dmg) | 앱을 Applications로 이동 |

두 설치 파일에는 SHA-256 확인 파일과 `HELP.md`를 제공합니다. 앱 도구바의 **도움말(?)** 버튼으로도 설명서를 볼 수 있습니다. 공개 릴리스의 설치 파일은 로그인 없이 내려받을 수 있습니다.

최신 개발 빌드는 [GitHub Actions](https://github.com/thlee/mdbom/actions/workflows/build.yml)의 성공한 실행에서 받을 수 있습니다. 아티팩트는 `MDBom-Windows-Setup-x64`, `MDBom-macOS-arm64`, 설치 없이 실행하는 `MDBom-win-x64`입니다. 릴리스는 검증된 빌드를 선택해 게시하며 자동 게시하지 않습니다.

- **Windows:** 현재 사용자에 설치하며 .NET 런타임이 포함됩니다. WebView2 Runtime이 없으면 설치 전에 안내하고 중단합니다. 새 설치 EXE를 실행하면 기존 설치 위치와 설정을 유지해 업데이트합니다. 제거는 Windows ‘설치된 앱’에서 할 수 있습니다.
- **Mac:** 실행 중인 앱을 종료하고 Applications의 앱을 교체합니다. 기존 설정은 유지됩니다.
- 두 플랫폼 모두 기존 기본 앱 선택을 강제로 변경하지 않습니다. 더블클릭 연결은 각 플랫폼 안내를 참고하세요.
- Windows 설치 파일은 미서명이고 Mac 앱은 ad-hoc 서명이며 Developer ID 공증은 없습니다.

[Windows 설치·파일 연결·빌드 안내](Windows/README.md) · [macOS 설치·파일 연결·빌드 안내](macOS/README.md)

## 주요 기능

- `.md` / `.markdown` 파일 열기, 연결 프로그램, 드래그앤드롭과 파일명 표시
- GitHub 스타일 본문, 표, 읽기 전용 체크리스트, fenced code block 구문 강조
- 문서·소스 단독 보기와 좌우·상하 분할, 원문 위치 기준 스크롤 연결
- 보기별 본문 폭, 확대/축소, 검색, 시스템·라이트·다크 테마
- 도구 패널 고정·자동 숨김 및 전체화면
- 외부 편집기의 저장 자동 반영과 읽던 위치 복원
- 서식이 적용된 본문 인쇄 및 PDF 저장
- 문서 시작의 YAML 메타데이터를 접힌 **문서 정보**로 표시

편집·저장 기능은 없으며 체크박스도 수정하지 않습니다. 소스 보기에서는 원문을 그대로 선택·복사할 수 있습니다. 소스와 렌더링을 전환하면 상단의 같은 문단·코드 줄을 최대한 유지합니다. 숨겨진 문법이나 문서 끝은 가까운 표시 위치로 연결됩니다.
## 인쇄 및 PDF 저장

문서를 연 뒤 도구바의 **인쇄 · PDF** 버튼 또는 **⌘P(Mac) / Ctrl+P(Windows)**를 누릅니다. Mac에서는 **File → Print…**도 사용할 수 있습니다. 인쇄 창에서 용지·방향·페이지 범위를 선택하고 출력하세요. Mac은 인쇄 창의 **PDF → PDF로 저장**, Windows는 미리보기의 **PDF로 저장** 대상을 선택할 수 있습니다.

소스 단독 보기나 분할 화면에서도 **서식이 적용된 본문만** 출력합니다. 도구바·검색창·소스 패널은 제외하고 밝은 배경을 사용합니다. 화면의 본문 폭 설정과 별개로 종이 폭에 맞추며, 긴 코드 줄과 표 셀은 줄바꿈합니다. 매우 넓은 표는 가로 방향 용지를 선택하면 읽기 편합니다. 앱은 출력 대화상자를 열며 실제 인쇄나 저장은 사용자가 선택합니다.

## 자동 새로고침

열어 둔 Markdown 파일을 다른 편집기에서 저장하면 **약 1초 안팎으로 자동 반영**합니다. 별도 설정 없이 기본으로 동작하며, 원본 파일에는 쓰지 않습니다. 파일 경로의 변경 정보만 주기적으로 확인하고 바뀌었을 때 내용을 읽습니다.

문서·소스 단독 보기와 좌우·상하 분할에서 각 창의 위치를 복원합니다. 앞부분에 내용이 추가되어도 주변 글을 찾아 읽던 위치를 최대한 유지합니다. 읽던 문단 자체가 삭제되거나 크게 바뀌면 가까운 위치로 이동할 수 있습니다. 보기 방식·폭·확대 설정은 유지합니다.

편집기가 임시 파일로 교체 저장하는 경우도 지원합니다. 파일이 잠시 없거나 읽을 수 없는 동안은 마지막 내용을 유지하고, 같은 경로에서 다시 읽을 수 있게 되면 갱신합니다. 동일한 내용을 다시 저장하면 화면을 다시 그리지 않습니다. 자동 확인 대상은 열린 Markdown 파일이며, 연결된 이미지 파일만 바뀐 경우에는 **새로고침** 버튼을 사용하세요.

## 폭과 글꼴 조절

도구바의 **폭**과 **글꼴**은 각각 독립된 토글 버튼입니다. 다시 누르거나 바깥 클릭·Esc로 닫으며, 다른 패널을 열면 기존 패널은 닫힙니다. 두 패널 모두 문서·소스 설정을 함께 보여 줍니다.

- **폭:** 좁게·기본·넓게, 슬라이더(600–1800px), 창 너비 맞춤
- **글꼴:** 시스템 기본·고딕·명조·고정폭, 글자 크기(12–28px)
- 각 화면의 설정을 따로 저장하며 **기본값으로**는 해당 패널의 설정만 초기화합니다.

## 보기와 도구 패널

두 앱은 **같은 떠 있는 도구 패널**을 사용합니다. 기본은 **항상 표시**이며, 문서 위에 떠 있는 패널은 파일 작업 / 보기 버튼 묶음 / 화면 설정 / 고정 버튼 순서로 배치합니다. 보기 버튼의 선택 상태와 스크롤 연결 상태를 바로 확인할 수 있습니다. 파일명은 창 제목에 표시합니다.

- **문서 / 소스 / 좌우 분할 / 상하 분할**: 소스는 계속 읽기 전용이며 복사·검색할 수 있습니다. 좌우는 소스가 왼쪽, 상하는 소스가 위쪽입니다.
- **분할 비율**: 구분선을 드래그합니다. 키보드로 구분선에 포커스를 둔 뒤 방향키로 조절하고 Home으로 50:50으로 돌아갈 수 있습니다. 범위는 20–80%입니다.
- **스크롤 연결**: 분할 모드에서 양방향으로 원문 위치를 연결합니다. 연결 아이콘 버튼을 끄면 따로 스크롤합니다. **검색 결과로 이동할 때는 연결 설정과 무관하게 양쪽이 같은 단어의 원문 위치로 이동**합니다. 문서 끝, 숨겨진 문법·HTML 등은 가까운 표시 위치로 연결됩니다.
- **폭 / 글꼴**: 별도 패널에서 문서와 소스 설정을 각각 조절합니다.
- **도움말(?)**: 읽던 문서를 유지한 채 내장 Markdown 설명서를 엽니다.
- **도구 자동 숨김**: 위쪽 가장자리 또는 ‘도구 ▾’에 포인터를 가져가면 패널이 나타납니다. 사용하는 동안 유지되며 벗어나면 숨습니다. 패널이 나타나도 문서 영역의 크기나 위치는 변하지 않습니다.
- **도구바 고정**: 오른쪽 핀 버튼으로 **항상 표시 / 자동 숨김**을 전환합니다. **⇧⌘H / Ctrl+Shift+H**도 같은 동작입니다. 별도의 완전 숨김 모드는 제거했으며, 이전 숨김 설정은 자동 숨김으로 이전됩니다.
- **전체화면**: 도구 패널 버튼 또는 Mac **⌃⌘F**, Windows **F11**로 전환하고 Esc로 나옵니다. 패널 표시 방식과 전체화면은 독립적입니다.

보기 배치, 분할 비율, 스크롤 연결, 도구 표시 방식은 로컬에 저장합니다. 소스/문서 단일 보기 전환은 **⌘U / Ctrl+U**도 지원합니다. 테마와 각 화면의 본문 폭도 저장합니다.

## 오프라인 동작과 지원 범위

markdown-it, DOMPurify, highlight.js 및 CSS를 앱에 포함합니다. 문서를 업로드하거나 CDN·외부 폰트·분석 서비스를 호출하지 않습니다. HTML은 표시 전에 정리하며 스크립트, 이벤트 핸들러, iframe, 폼, 임의 스타일을 제거합니다. 각 호스트의 요청 제한과 CSP가 원격 자산을 차단합니다.

로컬 이미지와 Markdown 링크는 문서 폴더 및 하위 폴더로 제한합니다. 원격 이미지는 로드하지 않고, 사용자가 누른 웹·메일 링크만 기본 앱으로 엽니다. 허용하는 이미지 형식·인코딩·파일 크기는 플랫폼 안내에 명시합니다.

Mermaid, LaTeX/KaTeX, SVG 및 편집 기능은 지원하지 않습니다. 100,000자 이상 코드 블록은 강조를 생략합니다. Windows WebView2 Runtime의 설치·시스템 업데이트는 앱의 오프라인 렌더링과 별개입니다.

## 소스에서 빌드

저장소 **전체**를 받으세요. 운영체제 폴더만 복사하면 공통 자산과 라이선스가 빠집니다.

| 환경 | 저장소 루트에서 실행 |
| --- | --- |
| macOS · Xcode 15 이상 또는 Command Line Tools | `./Scripts/build-app.sh` 후 `./Scripts/package-dmg.sh` |
| Windows · .NET 8 SDK | `./Windows/scripts/Publish.ps1 -OutputDirectory dist/MDBom-win-x64` |
| Windows 설치 EXE · Inno Setup 6.3 이상 | `./Windows/scripts/Build-Installer.ps1 -PublishDirectory dist/MDBom-win-x64 -OutputDirectory dist/installer` |

웹 자산은 커밋되어 있어 일반 앱 빌드에 Node.js가 필요하지 않습니다. Windows 최초 NuGet 복원에는 인터넷이 필요합니다. 웹 원본이나 의존성을 바꿀 때만 `npm ci --ignore-scripts`, `npm run bundle`, `node Scripts/check-assets.mjs`를 실행합니다.
