# 엠디봄 공식 홈페이지

GitHub Pages: https://thlee.github.io/mdbom/

`main` 브랜치의 `/docs` 폴더에서 게시합니다. 별도 빌드 의존성은 없습니다.

- index.html: 한국어 소개·기능·설치 안내·FAQ
- style.css: 반응형 디자인
- app.js: 문서/소스 예시와 테마 전환
- assets/icon.png: 엠디봄 아이콘

다운로드 기본 링크는 GitLab 정식 릴리스, 보조 링크는 GitHub Releases입니다. 새 버전을 공개할 때 두 링크와 버전·OS 요구사항을 확인해 수정하세요. 기존 1.0 배포처 간 아이콘·체크섬 차이는 다운로드 안내에 명시했습니다.

로컬 확인: `python3 -m http.server 4174 --directory docs` 실행 후 http://localhost:4174 에 접속합니다.

웹 예시는 앱 화면을 설명하기 위한 HTML이며 실제 화면 캡처가 아닙니다. Sites 확인본과 별도로 이 폴더를 공개 홈페이지의 소스로 관리합니다.
